# Production exit criteria

`0.2.0-rc.1` is not the requested complete enterprise product. The reference integrations remove specific prototype limitations; they do not close all 346 acceptance contracts. The status ledger has 116 partial, 227 not started, 3 blocked and 0 fully verified. Do not reduce the promised scope or relabel unfinished modules to pass the gate.

## Remaining engineering, in dependency order

1. **Identity and trust:** approved real MFA/step-up, directory lifecycle provisioning/suspension, session inventory/recovery, workload identities and all required persona/folder/delegate access paths. Verify actual IdP key/session policy and browser callbacks under TLS. Preserve independent WordPress/vault trust.
2. **Full core lifecycle:** folder/file-plan inheritance, schema-versioned metadata, required business formats/resumable capture/quarantine, safe conversion/previews, complete workflows/assignments/escalations, retention schedules/overlapping holds/legal discovery/disposition evidence and required purge semantics. Existing flat records and soft deletion are partial.
3. **High-assurance mode:** public recipient/device/group/recovery protocol, independent signed native client and update path, key verification/transparency, secure native storage, explicit recovery/no-recovery policies and cross-entity authorization. The unsigned file utility does not implement this. Obtain qualified protocol review before release.
4. **Persistent self-hosted platform:** hardened web runtime/ingress TLS, private service network, sealed persistent Bao with approved service identity/policy, restricted persistent PostgreSQL and S3 IAM/object-lock policy, queue/service identities, least-privilege runtime, regional deployment and monitoring. Replace all dev-mode/tmpfs services. Load-test serialized transactions and implement a justified concurrency strategy before any throughput promise.
5. **Audit/recovery:** independent immutable checkpoint/event sink with authentic latest-head retrieval; coordinated encrypted immutable/offline backups of DB/objects/identity/key roots and configuration; isolated recovery plus current revocation/ACL/hold reconciliation. Measure wrapping-service unavailability, recovery from corruption or ransomware, failover, RTO/RPO and selective restores. Local snapshots do not cover the managed stack.
6. **Delivery/assurance tooling:** remotely run the pinned CI jobs; full SAST/SCA/image and transitive dependency SBOM, DAST and adversarial format corpus; signed provenance/artifacts/update custody; tested upgrade/rollback/canary; WordPress Plugin Check/WPCS/multisite and real browser form/nonce regressions. Source-only Gitleaks and a component inventory do not complete these controls.
7. **Product completeness:** implement every other unchanged contract in the [traceability ledger](../requirements/traceability.csv), including localization/a11y, migration, optional AI safeguards, sharing/data rooms, native/mobile and enterprise modules as specified. Record acceptance against the exact requirement and both applicable modes, rather than promoting an entire module from a single component test.

## Evidence that requires real accountable people

The owner must appoint actual sponsors and independent security/cryptographic assessors; obtain findings, remediation/retest reports, legal/privacy/records/jurisdiction and retention decisions, verified support/security contacts, native localization and accessibility assessment, customer pilot/UAT and operational drill approvals. Bind final go/no-go to the exact source/image/artifact digests and deployment configuration with named signatories and dates. No AI council, generated signature or waiting period supplies those approvals.

G0–G8 remain in [READINESS](READINESS.md). After engineering and evidence are genuinely complete, replace the unconditional production denial with an independently reviewed attestation-validation policy; do not add a bypass switch, use staging as production, or make the environment guard the only release control. No actual production environment or public release was authorized/configured in this work, and none was deployed.
